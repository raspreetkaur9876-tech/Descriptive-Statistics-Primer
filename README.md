# Descriptive Statistics Primer

## About the Project
This project uses Microsoft Excel to analyze numerical data with descriptive statistics. It helps us understand the average values, middle values, variation, and distribution of data.

## Objectives
- Calculate mean, median, and mode.
- Calculate standard deviation.
- Find minimum and maximum values.
- Calculate the 25th and 75th percentiles.
- Understand data spread and possible skewness.

## Tools Used
- Microsoft Excel
- Titanic dataset (practice data currently used)

## Dataset
The project contains five numerical columns:
- Age
- Fare
- Survived
- SibSp
- Parch

**Note:** The current workbook uses 30 practice records for learning Excel formulas. The complete Titanic dataset should be added before using this project for final dataset-based analysis.

## Project Files
- `Descriptive_Statistics_Primer_Project.xlsx` — Excel workbook containing the data, summary statistics, and interpretation.

## Key Learnings
- Mean represents the average value.
- Median represents the middle value.
- Mode represents the most frequently occurring value.
- Standard deviation measures how spread out values are.
- Percentiles help us understand the distribution of data.

## Conclusion
This project provides practical experience in using descriptive statistics to summarize numerical data and interpret its important characteristics.
